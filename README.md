# 星愿高塔 · 三人的远征

公主连接非官方同人卡牌远征。开局选择三名伙伴，围绕专属卡牌、分支升级与遗物挑战三幕高塔。

在线试玩：[星愿高塔](https://satoshi0619.github.io/starlit-tower-redive/)

当前版本：3.10.0 公开试玩版。发布构建关闭并排除测试胜利工具。

明亮主题：奶油白、天空蓝、樱粉与薄荷绿，统一封面、组队、地图、战斗、商店、事件、奖励和弹窗。保留单屏战斗布局与既有玩法。

游玩指南面向首次登塔：先解释目标、共用行动和手牌，再按操作顺序上手。细则以常见问题展开，附三人配合例子；指南不包含更新记录。

18名角色，三幕16节点、10场主线战斗，登顶后可选一场回响。Boss单独出战，第一、二幕采用放大立绘；五位主线Boss具有更鲜明的攻击节奏和阶段变化。战斗提供出牌及结束回合预览。

蓄势：支付1行动，本轮全队未受到生命伤害时，下轮增加1行动，最多4行动。本轮已受伤不能蓄势；蓄势后受伤会被打断，已支付的行动不返还。护盾完全挡住及主动支付生命不算受伤，毒和反伤计入。

进度保存在访问者自己的浏览器，沿用原线上存档入口；网页不提供账号或云存档。更新后可继续旧局，活动中的旧Boss保留已记录的战斗节奏。首次交互后可播放声音。

角色、原版图像、动画、配音及音乐属于 Cygames 等相关权利方。影音与素材来源记录于 assets/ 中相应的 manifest.json 及 CREDITS.md。
