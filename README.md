# 星愿高塔 · 三人的远征

公主连接非官方同人卡牌远征。开局选择三名伙伴，围绕专属卡牌、分支升级与遗物挑战三幕高塔。

在线试玩：[星愿高塔](https://satoshi0619.github.io/starlit-tower-redive/)

当前为 v3.26 公开试玩版。

在高塔夜景前，点开伙伴牌可以查看她的招式和起始牌，再选「组队出发」进入编队。有远征存档时，标题画面会展示你的小队和所在场景，点「继续远征」就能回到上次停下的地方。

在兰德索尔广场选择三名伙伴，可以看全队入场、手动换人或调整前中后排。可可萝和望的立绘已对齐同伴。

普通近战会接近敌人出招，11 种魔物会完整举手、挥击和收势。命中时能看到格挡、碎盾和受击后退。安娜「冥姬宣言」的短片直接接战场命中，配音收尾时可以继续出牌。

新开远征，第一幕的同一个岔口可以选重甲卫士或坚果伏击，两场的奖励相同。卫士第二轮重斩前排，第三轮卸甲停手。坚果射手首轮各打 5 点，击倒一名，另一发立即降至 3 点。旧远征沿用开局时的地图。

想看鼓舞如何强化连击，可以选「守护反击」队，输入种子 `GLOW5`，从「草丛里的动静」出发。战后领取怜的「连续剑舞」，在战前营地恢复，再选「坚果伏击」。第一轮用可可萝鼓舞怜，再出剑舞，三击依次打出 8、3、3。第一击会显示鼓舞来源，轻量模式以状态图标提示。

首页会显示图片加载进度，提前准备角色立绘与头像、敌人、Boss、遗物、商人和场景图片。可以等待图片就绪，也可以直接进入选人。当前队伍的必杀短片和配音在后台准备。

旅人的小铺用医疗箱、短剑和背包标出「旅途补给」「招式练习」和「整理行囊」。每位同行角色有两张不同的招式可选，卡面头像标明招式归属。继续之前停在小铺的存档，也能看到补齐的招式，已经买过的卡会保留购买标记。

战场由远景、地面、薄雾与近景组成。桌面移动鼠标时能看到视差，角色出招、格挡和 Boss 转势会带动战场。设置中的轻量特效会减少镜头移动。

Boss 进入第二阶段时，战场会亮起红色 WARNING。二阶段首招有独立的蓄力与命中演出，原作短片与配音由招牌技触发。主线与回响均可体验。

明亮主题：奶油白、天空蓝、樱粉与薄荷绿，统一封面、组队、地图、战斗、商店、事件、奖励和弹窗。保留单屏战斗布局与既有玩法。

游玩指南面向首次登塔：先解释目标、共用行动和手牌，再按操作顺序上手。细则以常见问题展开，附三人配合例子；指南不包含更新记录。

开局选择三名同行伙伴，沿分岔路线登塔。普通战、精英战、营地与商店以图标区分，幕末 Boss 在进战时揭晓。战斗提供出牌和结束回合预览，登顶后可选择一场回响。

蓄势：支付1行动，本轮全队未受到生命伤害时，下轮增加1行动，最多4行动。本轮已受伤不能蓄势；蓄势后受伤会被打断，已支付的行动不返还。护盾完全挡住及主动支付生命不算受伤，毒和反伤计入。

进度保存在访问者自己的浏览器，沿用原线上存档入口；网页不提供账号或云存档。更新后可继续旧局，活动中的旧Boss保留已记录的战斗节奏。首次交互后可播放声音。
